NASA DATA AND RESOURCES
- NASA JPL OPERA DSWx-S1 v1, via NASA Earthdata / PO.DAAC: surface-water and inundated-vegetation classifications, used as secondary evidence alongside Sentinel-1. https://www.jpl.nasa.gov/go/opera/products/dswx-product-suite/
- NASA–ISRO NISAR L2 GCOV V1 and provisional V1, via Alaska Satellite Facility (ASF) DAAC: L-band HV backscatter darkening, used as secondary evidence where acquisitions are available. Provisional data may be reprocessed. https://search.asf.alaska.edu/  https://nisar.jpl.nasa.gov/
- ASF HyP3 INSAR_ISCE_MULTI_BURST, using Copernicus Sentinel-1: interferometric coherence loss on built-up land, a possible flooding indicator. https://hyp3-docs.asf.alaska.edu/

OTHER DATA AND MAP RESOURCES
- Copernicus Sentinel-1 RTC VV, via Microsoft Planetary Computer; acquisition inventory from Copernicus Data Space: primary flood replay and historical reference. Contains modified Copernicus Sentinel data 2024–2026. https://planetarycomputer.microsoft.com/dataset/sentinel-1-rtc  https://dataspace.copernicus.eu/
- Copernicus DEM GLO-30, 2021, via AWS Open Data: terrain and slope filtering. Contains modified Copernicus DEM GLO-30 data. https://registry.opendata.aws/copernicus-dem/
- ESA WorldCover 2021 v200: land-cover classification used in processing. © ESA WorldCover project 2021, CC BY 4.0. https://esa-worldcover.org/
- EOX Sentinel-2 cloudless 2024: contextual imagery, not a flood observation. Sentinel-2 cloudless 2024 by EOX IT Services GmbH (contains modified Copernicus Sentinel data 2024), CC BY-NC-SA 4.0; non-commercial use only. https://s2maps.eu/  https://creativecommons.org/licenses/by-nc-sa/4.0/
- Philippines COD-AB v03, PSA/NAMRIA via OCHA Humanitarian Data Exchange: barangay boundaries; CC BY-IGO. https://data.humdata.org/dataset/cod-ab-phl
- OpenStreetMap contributors: map features, building footprints and mapped trees, ODbL. Basemap tiles are supplied by OpenFreeMap using the OpenMapTiles schema; a Protomaps OSM-derived extract is also used for generated tree placement. Additional tree fill is decorative, not observed. https://www.openstreetmap.org/copyright  https://openfreemap.org/  https://openmaptiles.org/  https://protomaps.com/
- DAHITI, DGFI-TUM, target 40866 (Laguna de Bay): lake-level altimetry shown as context. https://dahiti.dgfi.tum.de/40866/
